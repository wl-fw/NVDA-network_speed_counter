 NVDA Network Speed Counter  

 Descrição  
Este complemento para NVDA permite monitorar a velocidade da internet em tempo real, relatando valores de download, upload e ping.  

  Como Usar  
- Pressione NVDA+Shift+X para testar a velocidade da internet.  
- O NVDA anunciará os valores medidos automaticamente.  

 Requisitos  
- NVDA 2024.1.0 ou superior.  

 Instalação  
1. Baixe o complemento no formato `.nvda-addon`.  
2. No NVDA, vá até Ferramentas > Loja de complementos.  
3. Clique em Instalar de fonte externa, selecione o arquivo baixado e confirme.  
4. Reinicie o NVDA para aplicar as mudanças.  

 Configuração  
Nenhuma configuração extra é necessária. Basta ativar o atalho e ouvir os resultados.
