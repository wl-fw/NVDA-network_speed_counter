net_speed_counter

Sumário

net_speed_counter é um complemento de código aberto para o NVDA que permite realizar testes de velocidade de internet (download, upload e ping) de forma acessível, com resultados falados e histórico integrado. Oferece interface gráfica, seleção de servidores, detalhes completos (servidor, IP, localização, etc.) e suporte a múltiplos idiomas (pt_BR, pt_PT, en, es, fr).

Sobre

Realize testes de velocidade de internet acessíveis diretamente no NVDA. Resultados são falados, salvos no histórico e exibidos em uma interface gráfica com opções para copiar informações ou personalizar exibição. Simples, acessível e ideal para todos os usuários.
